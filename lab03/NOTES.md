журнал воркшопа

\* git diff - показывает разницу между состояниями (коммитами или файлами).

\* git show - показывает изменения и информацию по конкретному коммиту.

\* git log - показывает историю коммитов (автор, дата, сообщения).

\* log -S - ищет коммиты, в которых изменилось количество упоминаний строки.

\* blame - показывает построчно, кто и в каком коммите изменил код.



\* git restore - сбрасывает незакоммиченные изменения до состояния HEAD.

\* git restore --source=HEAD\~2 - извлекает версию файла из коммита двухшаговой давности.

\* Если бы мы не сделали сброс, наши локальные незакоммиченные правки были бы безвозвратно перезаписаны версией из source.



\* git revert - создает новый коммит, обращающий изменения старого, сохраняя всю историю.

\* git reset --hard - удаляет коммиты из истории и стирает файлы.

\* В публичной истории revert безопаснее, так как reset затирает историю, ломая синхронизацию у коллег, работающих с тем же репозиторием.



\* Ветка - это динамический (подвижный) указатель, смещающийся с новыми коммитами.

\* Тег - это статичная (неподвижная) ссылка на конкретный исторический коммит.
