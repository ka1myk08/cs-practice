Рабочая папка — это текущая папка на вашем компьютере, в которой вы физически видите и редактируете файлы проекта. Здесь находятся все ваши черновики и незафиксированные изменения.

Индекс — это временная промежуточная зона. В индекс добавляют те изменения, которые вы хотите включить в следующий коммит.

Коммит — это сохраненный снимок (слепок) состояния вашего проекта в истории Git. Каждый коммит имеет уникальный идентификатор (хэш) и фиксирует изменения, которые были перенесены из индекса.

Git — это программа (инструмент контроля версий), которая установлена прямо на вашем компьютере. Она работает локально, отслеживает изменения в файлах, делает снимки истории (коммиты) и не требует интернета.

GitHub — это веб-сайт (облачный сервис) в интернете. Он служит «удаленным хранилищем» (хостингом), куда разработчики отправляют (делают git push) свои локальные репозитории, чтобы делиться кодом с командой, хранить бэкапы проекта и автоматизировать проверки.

git status — показывает текущее состояние рабочей директории и индекса (какие файлы изменены, а какие готовы к коммиту).

git diff — показывает незакоммиченные изменения, которые еще не были добавлены в индекс.

git diff --staged — показывает изменения, которые уже добавлены в индекс и готовы к следующему коммиту.

Ветки

Ветка — это независимая линия разработки (указатель на коммит), которая позволяет работать над новой задачей, не меняя основной код в ветке main.

При создании нового коммита текущая ветка автоматически сдвигается вперед, указывая на этот новый коммит.

Слияние — это процесс объединения изменений из одной ветки в другую.
